C++ Console Application

Project One Title

The Rock-Paper-Scissors application is a custom, console-based game built in C++ designed to demonstrate fundamental programming concepts, object-oriented design, and interactive game loop logic.

Key Features

  • Play Interactive Rounds: Compete directly against a computer opponent by choosing Rock, Paper, or Scissors.
  • Track Scores: Monitor your performance and see how you stack up against the computer.
  • Input Validation: Ensure that only valid choices are accepted, providing a smooth and error-free gaming experience.

What I Learned

The Challenge: Preventing the program from crashing or looping infinitely when a user types letters, symbols, or invalid numbers instead of the expected menu options. The Solution: Implemented robust input validation routines using std::cin.fail() and std::cin.clear() to flush bad data from the input buffer and prompt the player safely.
